## 1. 当前系统边界

- macOS 本地、单人、离线；
- 十类内容：MD / TXT / PDF / DOCX / PPTX / HTML / JSON / CSV / LOG / 图片 OCR；
- LanceDB 向量 + ICU 中文 FTS，RRF 融合；
- `bge-large-zh-v1.5` + `bge-reranker-large`；
- 动态文件 scope：资料库多选文件，API/CLI 支持 `doc_ids/file_paths`；
- 默认检索策略：`auto`（无 scope → full，有 scope → hybrid）；
- 本地 Web UI：搜索 / 资料库 / 同步 / 设置。

## 5. 归档

`docs/archive/` 保存历史实施记录：

- Foresight 借鉴分析；
- P0/P1/P2 实施记录；
- 早期代码评审、交互改进、Spotlight 评测；
- 自适应切片早期记录。

这些文档只用于追溯，不作为当前设计依据；当前结论以活动文档和 [活动报告索引](../reports/README.md) 为准。

---

## 6. 文档约定

- **DOC-xx**：跨步骤设计文档；
- **STEP-xx**：单步实现与验收；
- 活动文档版本统一标 `1.2.0.dev0`；
- 历史文档保留原始版本，不再更新；
- 需求变更先改总体方案，再改步骤文档，最后改代码；
- 每次 release 后更新本页版本表与 [评测方案](03-评测方案.md)。
